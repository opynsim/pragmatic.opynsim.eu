Example Data
============

Some guides in this handbook contain examples that load resources (e.g. models,
experimental data) from disk. In those cases, we only use resources from this
zip file:

.. rst-class:: text-center my-4 btn btn-primary btn-lg fw-bold text-white

`📥 Download pragmatic_resources (ZIP) <../pragmatic_resources.zip>`_

Guides assume these resources are unzipped into a directory called
``pragmatic_resources`` in your current working directory. Run this
Python code if you don't know where that is: ``import os ; print(os.getcwd())``.
IDEs like :doc:`pycharm` or :doc:`vscode` typically set your project's
directory as the current working directory whenever you click the run
button.

If you're unsure how to unzip the directory and move it to the correct place,
search/LLM for a guide. Most operating systems have in-built support for ZIPs but
it changes over time.
